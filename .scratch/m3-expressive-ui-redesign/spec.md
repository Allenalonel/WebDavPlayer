# Spec: Material 3 Expressive 界面重构、全天候全域动态取色与流体交互 (M3 Expressive UI Redesign, Global Dynamic Theming & Fluid Interaction)

Status: ready-for-agent

## Problem Statement

作为在 Android 移动端使用 WebDAV 音乐播放器的用户，在日常浏览曲库、整理歌单及播放音乐时，面临以下六类核心视觉、交互与手势可用性严重问题：

1. **底栏整体过高，严重挤占屏幕纵向可视视口**：
   底栏（NavigationBar + MiniPlayer）总占屏高度高达 168dp，加上系统手势条垫片后，页面下半部近三分之一的垂直空间被霸占，歌曲列表与媒体库目录被严重压缩，列表浏览极其局促沉重。
2. **顶栏老旧单薄、滚动折叠易诱发全页面手势死锁**：
   顶栏采用普通单行小型栏，缺乏现代 Material 3 Expressive 的视觉呼吸感；此前尝试自定义滚动折叠时，由于未遵循 Compose 官方嵌套滚动协议设置 `heightOffsetLimit`，导致 `nestedScrollConnection` 将向上滚动手势 100% 全部消耗吞噬，引发**全页面无法上下滑动（Scroll Broken）的致命缺陷**；且滑动收起时文字突然横向居中跳跃，顶栏堆砌冗余加号。
3. **歌单歌曲界面无法感知在播歌曲**：
   在媒体库中播放歌曲时，音轨封面有跳动的等化器波形指示（`EqualizerTrackIndicator`）；然而切换到歌单歌曲详情页时，当前正在播放的曲目没有任何高亮、波形动画或视觉指示，用户无法获知正在播放哪一首歌曲。
4. **浅色模式下小字体与胶囊对比度失衡糊成一团**：
   在浅色模式下，歌曲副标题、更新日期及歌单曲目数胶囊（Pills）使用了浅灰色字体与浅灰底色，文本对比度严重不足（低于 3.5:1），在日光或浅色背景下完全看不清，产生严重视觉糊字缺陷。
5. **搜索与多选交互粗糙缺乏现代感**：
   全屏搜索界面顶部带有生硬切断的通栏大横条背景，严重挤占视线；长按歌曲缺少优雅集成的现代多选操作胶囊，批量添加到歌单或下一首插队播放操作繁琐。
6. **全屏播放器质感陈旧且不支持多端响应式**：
   全屏播放器使用老旧的圆形黑胶唱片，不支持高质感方形大封面；且采用写死像素布局，无法在小屏紧凑设备、大屏旗舰及折叠屏/平板模式下自适应呈现最优分屏排版。

## Solution

全面对齐 Google Material 3 Expressive (M3E) 官方最新设计语言与移动工程实践，建立集“流体折叠顶栏 + 紧凑流体底栏 + 全天候全域动态取色 + 纯正药丸搜索 + 悬浮多选胶囊 + 响应式双分栏”于一体的现代化应用体验，并从底层彻底杜绝任何手势拦截与滑动死锁：

1. **底栏高度流体瘦身与 Scaffold 相对 24dp 黄金避让**：
   - 将 NavigationBar 压缩至 58dp，MiniPlayer 瘦身为 52dp 饱满药丸，底部总高度降至 **114dp**（直降 32% 占屏高度，释放 54dp 内容可视区）；
   - FAB 采用 Compose Scaffold 相对流体堆叠流，与 MiniPlayer 维持 **24dp 舒展黄金呼吸间距**，彻底杜绝元素遮挡。
2. **正统 M3E 连续流体折叠顶栏（安全手势契约与全程左对齐）**：
   - 彻底废除任何破坏嵌套滚动协议的自定义伪顶栏实现；
   - 必须基于 Compose Material 3 官方测量规约（由组件内部担保 `heightOffsetLimit` 测量），或对不需要折叠的页面彻底禁止悬挂 `scrollBehavior.nestedScrollConnection`，从根源保障**页面 LazyColumn 上下滑动 100% 丝滑无阻**；
   - 展开大标题与收缩后小标题水平基准线全程严格左对齐，彻底消除居中突兀跳跃；伴随 24px 毛玻璃雾化弥散，彻底移除顶栏多余加号。
3. **歌单与媒体库在播状态全域统一**：
   - 歌单歌曲详情行接入播放器会话状态，当前播放曲目封面覆盖 3 柱跳动音波（`EqualizerTrackIndicator`，暂停时静止），主标题以 Primary 强调色加粗高亮，视窗间状态严格对齐。
4. **全天候（深色/浅色模式）全域音轨动态取色系统**：
   - 色彩提取引擎基于音轨封面种子色通过 HCT Tonal Palette 同时推导全域暗色与全域浅色色阶，整机大背景（Background）、卡片底色（SurfaceContainer）及所有组件全天候随切歌 100% 丝滑换肤；
   - 浅色模式次级文本重构为深色石板墨炭色（`#3A3546`），数量胶囊重构为 Primary 浅容器底配墨色加粗字，对比度达到 WCAG AAA 8.5:1 超高清标准；
   - 废除引起全树逐帧重组掉帧的 17 色动画机制，采用高效稳定的色彩刷新方案。
5. **纯正 M3E 独立药丸搜索舱与悬浮多选胶囊**：
   - 彻底剔除通栏大横条背景，顶部悬浮 26dp 独立药丸搜索舱（44dp 状态栏安全避让），集成历史胶囊、即打即搜与一键切歌；
   - 长按歌曲触发多选状态：列表浮现复选框，MiniPlayer 优雅退让，底部弹出 28dp 悬浮多选操作胶囊（`下一首播放` + `添加到歌单`），顶栏转换为上下文操作栏。
6. **方形大封面、动感歌词与 WindowSizeClass 响应式双分栏**：
   - 全屏播放器升级为 28dp 方形圆角大卡片（Squircle 250x250，带环境光晕与 clamp 流体比例）；
   - 逐行双语动感歌词支持高亮发光与点击精准 Seek 跳转；
   - 在平板/折叠大屏（660dp+）模式下自动自适应为左右双栏分屏（左侧大封面，右侧沉浸歌词）。
7. **规范应用品牌名称**：
   - 全局各处正式校准显示名称为符合 WebDAV 协议标准的 `WebDAVPlayer`（DAV 全部大写）。

## User Stories

1. 作为在长歌单中翻找歌曲的用户，我希望底栏高度整体精简收缩，以便屏幕能多露出 2~3 首歌曲，浏览更高效开阔。
2. 作为在任何界面浏览曲库的用户，我希望在上下滑动列表时触摸响应丝滑灵敏，以便没有任何卡顿或滑动死锁失效的现象。
3. 作为正在歌单详情页听歌的用户，我希望正在播放的歌曲封面能显示跳动的音波动画且标题高亮，以便我一眼看清当前播放进度。
4. 作为在歌单中暂停播放的用户，我希望在播歌曲的封面音波条变为静止状态，以便我清晰感知当前的暂停回放状态。
5. 作为在媒体库目录向上滚动的用户，我希望顶栏大标题平滑收缩时文字始终保持左对齐，以便视线焦点不会因文字突然居中而产生跳跃眩晕。
6. 作为向上滑动列表的用户，我希望顶栏收缩后内容能平滑滑过半透明毛玻璃后方，以便界面层次充满现代呼吸感且无空白悬空。
7. 作为歌单与服务器管理界面的用户，我希望右下角的 FAB 悬浮新建按键与 MiniPlayer 保持舒适的距离，以便操作顺手且绝不遮挡正在播放的曲目。
8. 作为在室外强光下使用浅色模式的用户，我希望歌单副标、更新时间与歌曲数量胶囊文字颜色浓郁清晰，以便在浅色背景下也能毫不费力地看清所有信息。
9. 作为享受音乐沉浸感的用户，我希望每次切歌时整个 App 的大背景和卡片底色都能随专辑封面色彩柔和变色，以便获得与当前音乐情感共鸣的全域氛围体验。
10. 作为在浅色模式下切歌的用户，我希望整机背景色能转换为与专辑呼应的淡雅粉紫、暖杏或冰蓝晨雾色，以便在明亮环境下享受细腻质感。
11. 作为在媒体库中查找特定歌曲的用户，我希望点击顶栏放大镜能以独立药丸胶囊展开全屏搜索，以便顶部通透干净且输入框不被状态栏和动态岛遮挡。
12. 作为经常搜索常听歌手的用户，我希望搜索界面能展示最近搜索历史胶囊，以便我点击胶囊即可秒级填词检索。
13. 作为即时检索的用户，我希望在搜索框中每输入一个字符，下方就能实时过滤匹配的曲目，以便我能以最少输入快速找歌。
14. 作为在搜索结果中找到想听歌曲的用户，我希望点击搜索结果能够直接起播并自动关闭搜索回到当前视窗，以便听歌流程丝滑顺畅。
15. 作为整理私人NAS曲库的用户，当我长按媒体库中的某首歌曲时，我希望列表出现复选框并弹出悬浮操作胶囊，以便我能方便地批量加入歌单。
16. 作为多选音频曲目的用户，当我勾选多首歌曲后点击“下一首播放”时，我希望它们能被一次性插队到播放队列前方，以便我连续欣赏喜欢的段落。
17. 作为在小屏手机（360dp）上使用的用户，我希望歌单列表行的副标题严格保持单行并自然省略，以便排版整齐不换行、不破相。
18. 作为在全屏播放器中欣赏专辑封面的用户，我希望封面是高质感的大圆角方形卡片并伴随环境光晕，以便视觉效果大气纯正。
19. 作为跟着音乐哼唱的用户，我希望在全屏播放器中点击歌词能直接跳转到对应的音频时间点，以便快速复听高潮部分。
20. 作为在折叠大屏或平板上听歌的用户，我希望全屏播放器能自动将大封面和动感歌词左右并排双栏展示，以便充分利用宽屏视野。
21. 作为查看系统应用列表与通知栏的用户，我希望看到的播放器名称规范大写为“WebDAVPlayer”，以便专业规范且避免缩写歧义。
22. 作为在多选模式下改变主意的用户，当我点击左上角叉号或物理返回键时，我希望多选状态平滑解除且 MiniPlayer 自动复位，以便操作符合移动端直觉。

## Implementation Decisions

### 1. 架构级底栏瘦身与 Intrinsic Scaffold 堆叠流
- 废止 ADR-0007 中的 160dp 静态垫底契约，由 ADR-0028 建立全新的 **114dp 紧凑流体底栏基准**：
  - `NavigationBar`: 固定高度收敛至 **58dp**；
  - `MiniPlayer`: 浮动药丸高度由 64dp 瘦身为 **52dp**（圆角 26dp）；
  - 静态安全垫底调整为 $58\text{dp} + 52\text{dp} + 4\text{dp} = 114\text{dp}$。
- **FAB 相对流体堆叠**：
  - 废除绝对坐标定位，将 FAB 纳为 Scaffold 底部堆叠体系中的弹性浮动层；
  - FAB 相对下方容器维持 **24dp 垂直净空**，MiniPlayer 显隐时由状态机平滑推升或降落。

### 2. 全天候双模全域动态色彩推导引擎与色彩解绑 (Color Decoupling)
- **彻底解绑 Android 12+ Monét 系统壁纸色 (`dynamicColor = false`)**：
  - 根主题默认必须将 `dynamicColor` 锁定为 `false`，彻底消灭系统强行读取手机桌面壁纸（发灰/发黄杂色）冲淡覆盖应用原生配色的隐性问题；
  - 默认优先呈现应用专属的深邃暗紫曜石黑（`#141022`）与柔和浅底，播放时由 `ArtworkColorExtractor` 从当前音轨封面种子色进行全域自适应推导；
- 在色彩提取模块中，由当前在播音轨封面采样种子色（Dominant Color），通过 HCT 色彩空间同时推导出：
  - **暗色全域色阶**：沉浸背景（Tone 6~8）、容器底色（Tone 12~14）、Primary（Tone 80）；
  - **浅色全域色阶**：柔和氛围浅底（Tone 96~98）、浅色容器（Tone 92~94）、Primary（Tone 40）；
- 根主题接入动态 `ColorScheme`，整机大背景、卡片底色、顶栏折叠层及底栏滑块全天候随切歌平滑换肤；
- 严禁在根主题中对大量颜色属性施加每帧 `animateColorAsState`（避免引起整树逐帧重组卡顿），采用确定性的高效状态流更新；
- 浅色模式次级文字强化为高对比度石板炭黑（`#3A3546`），数量胶囊重构为 `primaryContainer` 底色配合 `onPrimaryContainer` 加粗字体，对比度严格达标 WCAG AAA（> 8.5:1）。

### 3. M3 Expressive 顶栏手势安全契约（手势零拦截铁律）
- **杜绝手势死锁的顶栏规约**：
  - 先前自定义组件因未配置 `heightOffsetLimit` 导致 `nestedScrollConnection` 吃掉全部手势的教训必须彻底杜绝；
  - 凡使用滑动折叠的视窗，必须基于 Compose Material 3 官方标准的 `LargeTopAppBar` 或由经过严密测量的布局内部正确设置 `heightOffsetLimit = -(expandedHeight - collapsedHeight)`，折叠收缩完成后立即释放滚动消费；
  - 凡不需要折叠的页面（如固定顶栏或特定子页面），**绝对严禁悬挂任何 `scrollBehavior.nestedScrollConnection`**；
  - 展开大标题与紧凑小标题水平基准线严格锁定左侧垂直轴（Consistent Left Alignment），杜绝居中跳跃；
  - 滚动时伴随 24px 毛玻璃弥散雾化，顶栏彻底移除加号按键，仅保留圆形 Tonal 图标。

### 4. 纯正 M3E 独立药丸搜索舱与长按多选胶囊
- **搜索系统**：
  - 剔除通栏大横条背景，顶部悬浮 26dp 饱满独立药丸搜索舱，预留 44dp 状态栏避让；
  - 包含历史胶囊 Chips、实时过滤歌曲列表与一键切歌。
- **长按多选胶囊**：
  - 长按触发临时多选状态机，列表项浮现勾选框，MiniPlayer 自然让位；
  - 底部以弹簧动效弹出 28dp 悬浮多选操作胶囊（`下一首播放` + `添加到歌单`），顶栏转换为上下文操作栏。

### 5. 列表全面卡片化 (Floating Card Flow)、拔除灰线与歌单 Hero Header
- **彻底拔除所有 `HorizontalDivider`**：
  - 严禁惯性修补！全应用各列表彻底废除 Android 传统的 `ListItem + HorizontalDivider` 灰线平底列表（旧版系统设置风格）；
  - 歌单列表行与音频列表行全面重构为 **16dp/18dp 独立悬浮圆角卡片项 (`surfaceContainer` 卡片容器)**，配合微外边距与触摸弹性微变，还原原型的流体卡片质感；
- **歌单详情页 Hero Header 落地**：
  - 顶部呈现 **80dp 渐变微圆角大封面卡片**、加粗大标题与 Primary 胶囊「播放全部」按键，与下方曲目卡片列表形成鲜明纵深层次；
- **歌单单列行规范与严格单行截断**：
  - 歌单列表采用 52dp 微圆角封面 + 数量胶囊 Pill + `white-space: nowrap; text-overflow: ellipsis;` 严格单行截断，任何分辨率绝不折成两行；
- **在播状态双向贯通**：
  - 歌单曲目行接入播放器 `sessionState`，封面叠加 3 柱跳动音波（`EqualizerTrackIndicator`），标题 Primary 加粗高亮。

### 6. 全屏大播放器专属质感、方形大封面与跨设备响应式断点
- **全屏播放器专属 M3E 质感**：
  - 顶部呈现“正在播放自 WebDAV”轻量纯净顶栏；
  - 播控主按键升级为 M3E 标志性的 **68dp Squircle（26dp 圆角方块）主播放键**，左右伴随 FilledTonal 药丸切歌按键，彻底淘汰原本简陋的小圆圈键；
  - 核心采用 **28dp 方形圆角大封面**（Squircle 250x250，具备环境光晕与 clamp 宽高比）；
  - 动感歌词支持双语逐行发光与点击精准 Seek 跳转；
  - 遵循 `WindowSizeClass`：紧凑屏（360dp）、标准屏（392dp）、大屏（430dp）与折叠屏/平板（660dp+ 左右双栏分屏）自适应。

## Testing Decisions

- **视觉保真度审计 (Visual Fidelity Review - Highest Priority)**：
  严禁仅凭“代码中存在某个参数/文字条目”而盲目打勾验收！每个组件的实现必须直接与 [`.tmp/prototype_m3_expressive.html`](../../.tmp/prototype_m3_expressive.html) 进行**像素级视觉保真度核验**：
  1. 检查是否存在未拔除的旧版 `HorizontalDivider` 灰线；
  2. 检查歌单和音轨是否真正呈现为独立 16dp/18dp 圆角卡片；
  3. 检查全屏播放主按键是否为 68dp Squircle 圆角方块；
  4. 检查歌单详情页是否真正具备 80dp 渐变大封面 Hero Header；
  5. 检查系统桌面壁纸是否被彻底解绑（未污染原生深紫黑底）。
- **手势与滚动连通性铁律**：
  每个界面的改造必须进行手势连通性验证：在任何情况下，用户向上/向下滑动 `LazyColumn` 必须绝对丝滑顺畅，绝不允许发生滚动被截胡、锁死或手势无效；
- **外部行为优先**：所有测试严格断言外部呈现状态与用户意图流转，严禁绑定私有内部实现细节；
- **核心被测模块**：
  - `PlaylistDetailViewModel`：验证在播音轨状态订阅、排序模式流转与多选批处理；
  - `DirectoryBrowserViewModel`：验证多选状态机与搜索过滤联动；
  - `ArtworkColorExtractor`：验证深色与浅色双模色阶计算的正确性、壁纸色解绑及高对比度兜底策略；
- **先验参考（Prior Art）**：
  - 参考已有的 `PlaylistDetailViewModelTest`、`DirectoryBrowserViewModelTest`、`ArtworkColorExtractorTest` 进行 Targeted 针对性回归。

## Out of Scope

- 本规范不包含持久化本地音频下载或离线缓存机制（始终遵循 ADR-0002 纯在线流式回放原则）；
- 本规范不包含自定义声学 DSP 均衡器音频调音台（硬件升采样遵循 ADR-0018 规范）；
- 本规范不变更底层的 WebDAV 网络认证协议层与 CUE 虚拟分轨解析器。
