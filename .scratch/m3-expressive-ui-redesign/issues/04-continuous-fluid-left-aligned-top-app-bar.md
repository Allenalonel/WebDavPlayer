# 04: M3 Expressive 连续流体折叠顶栏（全程严格左对齐与纯净化）

**What to build:** 
用户在媒体库、歌单列表、歌单详情及服务器等所有主要视窗中向上滑动页面时，顶栏大标题高度平滑连续收缩至 0，紧凑顶栏无缝锁定在 56dp，内容滑过 24px 毛玻璃雾化弥散层后方，彻底消除空白悬空与生硬切断感。同时，展开大标题与收起后小标题的水平基准线全程严格保持左对齐，文字仅在纵向上平滑上浮微缩，绝对不发生任何横向突兀居中跳跃。顶栏彻底移除冗余的“加号（+）”按键，仅保留圆形 Tonal 搜索与更多菜单，视觉极其纯净呼吸。

**Blocked by:** 01: 品牌名称规范化与全天候全域音轨动态取色主题系统

**Status:** ready-for-agent

- [ ] 各视窗顶栏接入原生 `TopAppBarDefaults.exitUntilCollapsedScrollBehavior()`，大标题高度随滚动连续平滑坍缩至 0，无空白悬空占位
- [ ] 展开大标题与收起小标题统一锁定左侧垂直基准线（Consistent Left Alignment），收起折叠过程中绝对不发生突兀居中跳跃
- [ ] 顶栏在滚动后呈现 24px 柔和毛玻璃弥散雾化效果，与全域动态背景柔和浸润，页面滑过时无生硬色块切断
- [ ] 彻底移除各视窗顶栏右侧所有的冗余“加号（+）”按钮，保持顶栏纯净留白
- [ ] 服务器管理界面在浅色模式下的卡片、图标与属性标签完成色彩重构，满足高对比度要求，彻底消除黑底糊字
- [ ] 在多种滑动速度与边界回弹场景下核验顶栏折叠与展开动效的物理平滑度
