# 02: 数据源自愈续连与字节计数熔断 (Resilient WebDAV Data Source with Transparent Range Reconnection & Content-Length Guard)

**What to build:** 实现具备透明自愈能力的流式数据源包裹层。当用户在弱网或网络瞬断环境下收听音频时，底层数据源在读取流中断或超时时自动记录当前已读取的字节偏移量，并以指数退避算法在后台自动发起 HTTP Range 续传请求接续数据流，解码器不重建、播放进度条不跳动、播放器平稳处于缓冲状态；同时，在遇到网络流提前断开时，通过响应头比对累计读取字节数与预期文件长度，未达标立即作为异常重连而非返回流结束，彻底防止假播完。

**Blocked by:** 01: 传输层 HTTP/1.1 协议锁定与流式超时调优 (Streaming Protocol & Timeout Hardening)

**Status:** ready-for-agent

- [ ] 流式数据源在网络读取中途捕获超时或 I/O 异常时，自动基于当前已读字节偏移发起 `Range: bytes=(offset)-` 断点重连。
- [ ] 重连过程采用指数退避机制（重试间隔平顶于 5~8 秒），重试期间对外平滑暴露缓冲状态，不向上层抛出致命中断异常。
- [ ] 遇到 HTTP 401、403、404 等非临时性错误时立即快速失败，禁止死循环重试。
- [ ] 流读取结束时实施 Content-Length Guard 字节校验：若响应头声明了实体大小但累计读取字节数不足，抛出异常转入断点重连，禁止向播放引擎返回伪流结束标志（EOF）。
- [ ] 整个重试与断点续传完全在内存输入流与网络传输层闭环，零持久化磁盘文件写入，严格符合 ADR-0002 纯流式约束。
- [ ] 自动化测试模拟弱网超时与提前断流，验证数据源自动发起正确的 Range 续传请求且读取数据完整连续。
