# 03: 会话层切歌管控与时长校验熔断 (Session-Managed Queue Progression with Duration Guard)

**What to build:** 彻底改造播放引擎与会话层的职责划分，将切歌流转的决策权完全收拢至会话层，并剥夺底层播放引擎自主跳过曲目的权力。播放引擎仅负责当前单曲的流式渲染，不再一次性装填全目录；当引擎派发播放完成事件时，会话层通过 Duration Guard 比对当前播放进度与音频总时长，若进度未达标判定为异常断流，拒绝切歌并触发原地恢复；只有当曲目真正播至尾声时，才自然推进队列，彻底杜绝有声书与长音频弱网跳集。

**Blocked by:** 02: 数据源自愈续连与字节计数熔断 (Resilient WebDAV Data Source with Transparent Range Reconnection & Content-Length Guard)

**Status:** ready-for-agent

- [ ] 底层播放引擎职责收敛为单一当前媒体项（或受控追加的下一项）的渲染容器，弃用批量全量装载目录列表的做法。
- [ ] 播放队列的流转索引推进权完全归属于应用会话层，底层播放引擎在遇到错误时禁止自主跳过曲目。
- [ ] 会话层在接收到播放引擎的播放完成信号时，比对当前播放进度与音频总时长（容差 3 秒）；进度不足时判定为意外截断，拒绝推进当前曲目索引，并在当前断点处发起原位恢复。
- [ ] 当曲目真正完整播放完毕且进度吻合时，会话层正确推进至队列下一首，并在列表末尾严格遵守 Folder Ring 目录环形闭环规则（回环至首曲，严禁跨文件夹）。
- [ ] 自动化测试验证底层意外上报播放完成时切歌被成功拦截并原地重试，真实播完时正常顺畅切换至下一曲。
