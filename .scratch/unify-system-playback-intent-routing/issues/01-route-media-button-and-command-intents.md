# 01: 统一媒体按键与命令意图至应用会话层 (Route Media Button and Command Intents to App Session)

**What to build:**
让用户通过蓝牙耳机、车载物理控制按键或有线线控触发媒体动作（播放、暂停、播放/暂停翻转、停止、上一首、下一首）以及通过系统媒体命令触发切歌时，这些事件端到端统一直接路由至应用会话层。解决停止（Stop）按键跳过会话层资源清理的缺陷，并将翻转控制交由会话层按当前真实播放状态机统一裁决。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 媒体按键事件中的播放指令直接派发给应用会话层的播放意图，不再绕过会话层操作底层播放引擎
- [ ] 媒体按键事件中的暂停指令直接派发给应用会话层的暂停意图
- [ ] 媒体按键事件中的播放/暂停翻转指令（包括耳机挂断/通话键）直接派发给会话层的翻转意图，由会话层内部依据真实播放状态统一裁决，不再在回调层读取底层引擎状态
- [ ] 媒体按键事件中的停止指令直接派发给会话层的停止意图，完整触发虚拟分轨时间线清理、弱网看门狗取消与会话持久化安全退出落盘
- [ ] 系统媒体命令请求（SeekToNext / SeekToPrevious 及其 MediaItem 变体）继续可靠派发至会话层的下一首与上一首意图
- [ ] 现有的媒体会话回调测试集迁移至应用会话层接缝进行断言，替换针对底层引擎调用计数的旧断言，所有意图派发分支均有测试覆盖
