✨ 3 款新方案的设计解析（全部取消底部分割横线）：

方案 1：悬浮胶囊药丸 (推荐)

  • 去横线方式：左右留白 16dp，采用 28dp 大圆角胶囊药丸，带微弱阴影浮动于界面上方。
  • 视觉感受：轻盈、现代、呼吸感最强，完全消除了原来从屏幕左边缘切到右边缘的生硬横线。
  • 适合偏好：喜欢精致无边界浮动感的用户。

方案 2：全通透极简沉浸

  • 去横线方式：背景完全一色到底，浅灰色输入框内嵌，右侧带有清晰的“取消”文字。
  • 视觉感受：类似 Apple Music、Spotify 等主流音乐软件的无界设计，简单纯粹。
  • 适合偏好：喜欢极简、无任何多余线条与阴影的用户。

方案 3：双层顶栏内嵌卡片

  • 去横线方式：顶部使用浅灰容器色块整体包裹，底部使用 24dp 大圆角收尾。
  • 视觉感受：结构稳重，上方有“曲库搜索”标题，下方为圆角搜索框，层次清晰。
  • 适合偏好：喜欢有明确顶栏结构与标题感的用户。
