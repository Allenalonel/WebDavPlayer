# 05: 纯正 M3E 独立药丸搜索舱与媒体库长按多选操作胶囊

**What to build:** 
用户点击顶栏搜索图标时，顶部干净通透无通栏大横条切断，悬浮展开一颗精致的 26dp 独立药丸搜索舱（Pill Search Capsule），顶部具备 44dp 状态栏避让，绝不遮挡系统时间与动态岛；支持最近搜索历史胶囊点击填词与即打即搜实时过滤曲目，点击曲目即可一键播放并自动收起搜索。当用户在媒体库中长按任意歌曲时，列表自动浮现勾选框，MiniPlayer 优雅退场让位，底部以 M3 弹簧动效弹出 28dp 悬浮多选操作胶囊（包含「下一首播放」与「添加到歌单」两个精致药丸按键），顶栏转换为多选上下文操作栏，用户可批量执行插队播放或加入歌单；搜索结果与多选列表上下滑动畅快无阻。

**Blocked by:** 02: 紧凑流体底栏 (114dp) 与 Scaffold 相对 24dp 避让 FAB, 04: M3 Expressive 连续流体折叠顶栏（全程严格左对齐与纯净化）

## Answer
- 全屏搜索界面顶部彻底剔除生硬横条色块，背景设为透明与整机动态色彩流体相融；顶部以 `statusBarsPadding()`（44dp）安全避让动态岛与状态栏。
- 搜索舱重构为精致的 26dp 独立药丸搜索舱（`RoundedCornerShape(26.dp)`，高度 52dp），左侧配备返回圆形按钮，右侧集成清除按钮。
- `SearchResultsViews` 接入包含“最近搜索”胶囊 Chips 与“热门标签”Chips，支持点击秒级填词与单项删除。
- 搜索结果点击曲目即时起播并自动平滑退出搜索（`viewModel.onSearchActiveChanged(false)`）。
- 媒体库长按触发多选，MiniPlayer 自动优雅退避，底部弹出 28dp 悬浮多选胶囊（`FloatingMultiSelectBottomBar`），退出多选时 MiniPlayer 自动平滑复位。
- 编写并验证通过多选批量插队播放（`batchPlayNext_preservesSelectedTrackOrderInQueue`）以及全部 `DirectoryBrowserViewModelTest` 单元测试。
