# 01: 品牌名称规范化与全天候全域音轨动态取色主题系统

**What to build:** 
用户在启动器图标、多任务卡片与通知栏标题中看到应用名称统一且规范地展示为 `WebDAVPlayer`。当用户在应用中播放任意歌曲时，无论系统处于深色模式还是浅色模式，整机大背景（Background）、卡片底色（SurfaceContainer）、顶栏折叠层及核心交互按钮，均 100% 自动向当前在播曲目的专辑封面动态提取色阶并进行平滑换肤。在浅色模式下，小标题、更新时间与文件属性等次级文本使用浓郁的深色高对比度（WCAG AAA 8.5:1 标准），杜绝任何文字与背景模糊混淆的缺陷。

**Blocked by:** None (can start immediately)

**Status:** resolved

- [x] 应用在 Android 启动器、系统任务切换器、通知栏及所有对外呈现位置的名称规范校准为 `WebDAVPlayer`（DAV 全部大写）
- [x] 彻底解绑 Android 12+ Monét 系统壁纸色（`dynamicColor = false`），默认锁定应用原生深邃暗紫曜石黑（`#141022`）与柔和浅底，杜绝系统壁纸色冲淡覆盖
- [x] 颜色提取引擎支持从音频封面种子色推导出全域暗色色阶与柔和浅色色阶，暗浅模式均具备独立完备的动态色谱
- [x] 根主题接入动态 ColorScheme，在播音轨切换时整机大背景（Background）与卡片底色（SurfaceContainer）丝滑渐变换肤
- [x] 杜绝引起全树逐帧重组卡顿的动画方案，采用确定性、高帧率的颜色状态刷新机制
- [x] 浅色模式下次级信息文字采用深色石板墨炭色（`#3A3546`），文本对比度严格达到 WCAG AAA 8.5:1 超高清标准
- [x] 针对无封面或破损封面的音频文件，色彩提取机制平滑回退至 Material 3 标准默认动态主题，无任何崩溃或色彩突变
- [x] 必须与 `.tmp/prototype_m3_expressive.html` 进行视觉比对核验，确保冷启动与切歌时整机背景氛围 100% 还原原型
- [x] 针对动态色彩提取与双模式色阶计算编写针对性单元测试并通过验证
