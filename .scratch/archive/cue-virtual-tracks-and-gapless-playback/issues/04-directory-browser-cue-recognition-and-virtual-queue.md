# 04: 目录浏览器 CUE 识别与虚拟分轨队列点播呈现

**What to build:**
在曲库目录浏览器中智能识别同目录下的 `.cue` 文件与其配套的整轨大音频（如 FLAC/WAV/APE），并在目录列表及播放队列抽屉（`PlaybackQueueBottomSheet`）中展开渲染虚拟分轨项。支持直观查看分轨序号、曲目标题、表演者与分轨时长；点击任意虚拟分轨即可瞬间从对应起始时间戳流式起播整轨音频。若当前正在播放某首虚拟分轨，其归属文件与分轨项均同步呈现动态等化器跳动指示器（`Equalizer Track Indicator`）。

**Blocked by:**
01: 纯内存 CUE 状态机解析器与 Virtual Track 领域实体, 03: 虚拟时间轴映射引擎（Virtual Timeline Engine）与零打扰元数据广播

**Status:** completed

- [x] 目录扫描与关联：在 `DirectoryBrowserViewModel` 中建立文件匹配逻辑，自动发现同目录与 `.cue` 关联的大音频实体。
- [x] 目录列表呈现：提供 CUE 专辑卡片折叠/展开视图或分轨列表抽屉，展示分轨序号、标题、表演者及格式标签。
- [x] 虚拟分轨点击起播：点击任意分轨，会话层装载该整轨音频并直接将流定位至该分轨的 `startTimeMs`，UI 立即显示该分轨元数据。
- [x] 播放队列同步：在 `PlaybackQueueBottomSheet` 中将当前 CUE 专辑的全部虚拟分轨作为队列项目呈现，支持随意点选切歌。
- [x] 动态等化器指示：当前正在播放的虚拟分轨高亮显示，并展示等化器跳动图标。
- [x] 编写测试覆盖：CUE 与大音频文件名关联逻辑、分轨点击分派与队列状态映射。
