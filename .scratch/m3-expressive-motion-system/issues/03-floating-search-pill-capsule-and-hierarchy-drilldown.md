# 03: M3E 悬浮搜索舱形变与媒体库层级穿梭

**What to build:** 为媒体库打造丝滑流畅的搜索展开与树状目录穿梭体验。实现顶栏 38dp 放大镜按钮以 M3E 容器形变平滑撑开为 26dp 饱满圆角的独立悬浮药丸搜索舱（`FloatingSearchPillCapsule`），同时搜索建议与历史 Chips 柔和下展；在搜索结果中点击“文件夹”实现搜索舱收缩归位并跨维度定焦降落（Focal Landing）；媒体库子目录进入采用双层绝对层叠架构，实现父目录向左 25% 视差后退、子目录从右侧 100% 弹性推入，伴随面包屑条末尾胶囊动态生长，彻底杜绝任何垂直跳动。

**Blocked by:** 01: M3E 动效基础设施与触控微缩修饰符

**Status:** claimed

## Acceptance criteria

- [ ] 在 `DirectoryBrowserScreen.kt` 中重构顶栏搜索交互：点击 38dp 放大镜按钮，搜索栏以 M3E 弹簧向四周扩张为 26dp 饱满圆角的 `FloatingSearchPillCapsule`，原顶栏标题优雅微透退让。
- [ ] 全屏搜索视图（`SearchView`）与历史记录 Chips 在搜索舱展开的同时自顶向下柔和滑入，点击返回箭头（←）以反向弹簧优雅收缩回 38dp 按钮并复位。
- [ ] 在搜索结果中点击文件夹项目时，触发搜索舱收缩归位并在媒体库中以轻微变焦淡入（`scaleIn(0.96f) + fadeIn()`）精准定焦降落至目标目录，面包屑条同步更新祖先路径。
- [ ] 重构媒体库子目录穿梭：进入子目录时，父级列表向左执行 25% 视差后退并微暗，新子目录自右侧 100% 弹性推入，面包屑条末端动态扩展新胶囊，消除垂直排版突变跳跃。
- [ ] 点击返回上一级或返回键时，对等执行逆向拉回：子目录向右 100% 滑出，父目录从左侧 25% 视差深处滑回眼前。
- [ ] 编写或更新目录浏览与搜索交互测试，验证搜索状态切换与层级推移行为。
