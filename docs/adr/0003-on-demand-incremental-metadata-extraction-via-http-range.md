# On-Demand Incremental Metadata Extraction via HTTP Range

## Context

在 WebDAV 远程文件浏览中，若每次进入目录都全量下载音频文件以读取 ID3/标签信息，会产生极大的流量消耗与严重卡顿；若仅显示原始文件名，则无法展示曲目标题、歌手、专辑与内嵌封面，降低播放器体验。

## Decision

进入目录时，先通过 WebDAV `PROPFIND` 获取文件列表并立即秒开渲染基础文件名；后台以受限并发利用 HTTP `Range` 请求仅截取文件头部/尾部数据分片，异步提取音频标签与封面，并持久化缓存至本地 Room 数据库中，避免重复请求。

## Consequences

- 保证了远程目录浏览的秒开响应速度，同时渐进式呈现富元数据与封面。
- 本地仅保存元数据与封面缩略图，不落盘音频流本体，符合零磁盘存储占用的原则。
- 在网络延迟较高或并发连接受限的 WebDAV 服务器上，可能出现标签信息稍有延迟呈现的现象。
